### 기술표준에 검토의견 작성 Agent

[제목] 기술표준에 검토의견 작성 Agent
*직무 : KBE 기술지식 체계 기획 운영, 기술표준 심의 및 검토의견 작성
*해결하고 싶은 현안 : 기존 작성한 회의록을 기준으로 아래 프롬프트까지 추가하여 
 회사내망 기준으로 기술표준 본문을 저장하고 해당 내용을 기준으로 기초 회의록을 출력
[운영기준]
1. 내 컴퓨터 안에서 만 구동되는 솔루션으로 작성되어야 함
2. HDX임으로 사내 폐쇄망 기준으로 운영 되어야 함
[개발내용]
1. 작성된 표준에 대한 평가 및 회의록 출력
: 심의진행시 작덩된 WordFile 설계표준, 시험검증표준, 가상검증표준에 대한 평가를 기준으로 회의록 작성 엑셀 출력
 *기존에 내가 작성한 회의록과 그 내용을 작성하게된 표준 원본을 내 컴에 저장
 *각 표준의 기본 Template 제공 학습
[개발필요 사항] 기존 작성된 표준을 평가하기 위한 프롬프트
 *기본 제공된 Template에 정리된 기준을 준수 하여야 함. 미준수시 미준수 내용을 기준 Template 기준으로 수정하라고 멘트 제공
 
 *기본 Template의 정해진 항목과 항목 설명 내용은 아래 설명 기준으로 작성되어야 함
 -1항 목적및 정의는 작성된 표준의 목적과 정의를 구체적으로 정리하여 제목의 내용에 대한 표준 문서의 목적과 정의를 구체적으로 정리 하여야 한다
 -2항 관련 표준 및 인용은 표준의 내용에 관련된 표준과 검토된 기술지식에 대한 문서번호화 제목이 정리되어야 한다
 -3항 용어정의는 표준에 사용된 용어에 대한 정의로 일반적인 상식이 아닌 작성된 표준에 적용되는 용어에 대한 정리와 설명이 구체적으로 정리되어야 한다
     정리된 용어정의는 해당 표준에 작성된 내용에 사용된 용어임으로, 작성된 표준 전체에 동일 기준으로 사용되어야 한다. 예로 ECU는 계속 EUC로 써야됨 한글로 이씨유 불가
  용어가 통일되게 사용하지 않은것도 지적 대상임
  *4항 설계절차/시험절차
  1)설계절차/시험절차는 설계 방법을 항목 순서 기준으로 정리함
  2)4.1 또는 4.2항에 설계절차, 시험절차를 iso 기준으로 FlowChart로 제시 해야됨
  3)4항 이하 설계, 시험관련 절차를 정리하며 가능하면 수식으로 제시하여 정리 해야됨
  4)작성되는 내용중 그림, 표에는 반드시 표1, 그림(Fig)1 등 번호가 기재 되어야 함
  5)1항 목적및 범위에 정리된 내용과 4항이하 설계, 시험절차에 정리된 내용을 비교하여 논리적으로 MECE 해야됨
  6)구체적 기준에 대해 근거를 명확하게 정수화 하여 표현하고, 관련된 표준,법규 등은 반드시 근거를 명확히 제시하여야 함
    제시된 표준 No,와 제목이 맞는지 확인  필요
  7)
 -5항 설계/시험 검증
  1) 설계 또는 시험 방법에 제시한 사항을 검증 하는 방법을 제시 해야됨
  2) 최대한 정성적인 아닌 정량적 기준으로 관련 근거를 제기하여야 함
  3)

 -7항 안전관련 사항으로 표준을 설계/시험하여 지켜져야할 안전 기준에 대해 정리 되어야함
 -8항 기타 Appendix로 표준 내용에 보완하여 설명을 추가
 *해당 내용을 내 컴 기반의 AI가 학습(가능하면 코파일럿)
