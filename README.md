# data09-15 · 기술표준 검토의견 작성 Agent

Word 기술표준(설계·시험검증·가상검증)을 Template 평가 기준 체크리스트로 점검해 수정 요청 문구가 담긴 회의록 초안 엑셀을 만드는 폐쇄망 전용 로컬 검토 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 이기욱 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 — 프로젝트 기획서 등록 (2026-09-28) |
| 다음 개발 | 표준 .docx를 읽어 항목 존재·순서, 표/그림 번호, 용어 통일, 인용 표준번호 형식을 자동 점검하고 판단 항목(MECE·목적 구체성 등)은 사내 승인 AI용 프롬프트로 내보내며 회의록 초안 엑셀을 출력하는 폐쇄망용 로컬 Python 도구(실제 양식·규칙은 표준 원본·Template·기존 회의록 확보 후 보정) |
